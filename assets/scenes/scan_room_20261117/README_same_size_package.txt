同尺寸原位条码版（2026-11-17）
用户允许生成新的可扫描内容。条码样式为一维 Code128，编号 C列R行 -> 两位列号+两位行号，例如 C3R3 -> 0303。
仅重印原贴图标签的内部；保留拍摄到的纸张外边缘，原 mesh 几何、UV、位置及原始资产均不改。
尺寸来自已有标定模型及原贴图的标签边界，不代表实物纸张毫米尺寸已经独立测量。
scene_same_size_code128.usda 是可移除材质覆盖层；isaac_environment 是未修改的原场景。
最初的合成大二维码版本不作为该版本交付。
same_size_before_after.jpg 每组上面是原图，下面是原位新条码。
footprint_validation.json 验证标签内部以外无额外改写（相对于同倍率基线）；same_size_labels.json 给出每张标签的 UV 坐标、模型尺寸及映射内容。
scan_test/report.json 是实际渲染解码/扫码枪测试结果；这不是完整 Agent 自主作业成功率。
在 fastwam-gui 容器内执行 bash launch_preview.sh g1 code128，可独立预览；原项目默认场景和已有服务不变。

测试结果：95 GPU7，30cm、640x480、32.8°水平视角，30/30 标签正确解码；G1 实际腕部扫码枪读出 C3R3 的 0303，扫码角度补偿为0°。仅单个已知目标的 IK/扫码验证，不是完整自主 Agent 成功率。173 CPU 验证原始资产8个不变、4个mesh几何及UV不变、32个碰撞体保留；原项目478个受检文件无改动。
